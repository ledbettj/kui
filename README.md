# WoW addons

Each folder is one addon. Link it into the game's `Interface/AddOns/`
under the same name.

- [KUI](KUI/README.md): a clean, minimal UI replacement for WoW forever.
- [QuestBros](QuestBros/README.md): see which friends have done, or are on, a
  quest, even while they're offline.

Lint everything with `luacheck .` from here; `.luacheckrc` is shared.
